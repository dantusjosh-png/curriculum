## How a course works

Every course follows the same structure — see [How It Works](how-it-works) for the full pedagogy.

1. **Syllabus** — modules from fundamentals to specialized depth
2. **Per module**: Lecture → Discussion → Application → Feedback loop
3. **Section reviews** — quizzes and synthesis prompts
4. **Capstone** — an integrative real-world project
